# OPA156 / OPA2156 (TI 36 V low-noise RRIO CMOS precision)

**Tier** C: niche / baseline · **Category** CMOS-input

*TI 36 V rail-to-rail I/O CMOS dual with low noise and low offset. Occasionally used where OPA1656-class parts appear, but audio-community praise is thin.*

**Technology:** CMOS input (per discovery notes; not re-verified this run). 36 V class, rail-to-rail input and output, low offset voltage, marketed as 'ultra low noise'. The KiCad symbol text, which paraphrases TI's device title, is 'Dual 36V, Ultra Low Noise, Rail-to-Rail Input/Output, Low Offset Voltage, Operational Amplifier'. It is not an audio-branded (Burr-Brown/SoundPlus) part.

## Why enthusiasts rate it

No Hi-Fi community praise was found. No sound descriptors, ASR or Groner measurements were retrieved, because web search was unavailable this run. On GitHub it shows up mainly in instrumentation: a patch-clamp amplifier and a DAQ board, with OPA1656ID listed as the pin-compatible alternate in the covg_clamp BOM. It also appears in one DIY audio preamp output stage (bengineer91/Preamp, OPA2156IDR). The discovery note calls it a 'higher-rail alternative to the OPA1656', which is refuted: the OPA1656 is also specified for 4.5 V to 36 V (±2.25 V to ±18 V) per SBOS901C. What the OPAx156 adds over the OPA1656 is rail-to-rail input and a low-offset precision specification, not more supply headroom.

**Typical uses:** Precision / instrumentation front ends (patch-clamp amplifier, DAQ), DIY audio preamp output/buffer stage (one GitHub project), Candidate in place of OPA1656-class duals where rail-to-rail input or low offset is wanted

**Caveats:**

- Not an audio-branded part; audio-specific THD+N data not retrieved
- Only SMD packages seen (SOIC-8, VSSOP-8), so DIP socket rolling needs an adapter
- Same 36 V supply limit as OPA1656 (no rail advantage)
- Praise evidence is thin; tier C inclusion rests on engineering specs, not community consensus

## Counterfeits

No counterfeit reports found. Web search was unavailable, so forums and marketplaces were not checked. It is a modern SMD-only TI part (SOIC-8/VSSOP-8) without the cult following that drives relabeling of DIP audio op-amps, so risk is presumably low. Buy from authorized distribution. Top-marking codes were not retrieved.
