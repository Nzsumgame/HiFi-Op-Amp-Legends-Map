# NJM2082 / NJM2082DD (New JRC / Nisshinbo JFET-input dual, improved NJM082)

**Tier** C: niche / baseline · **Category** JFET-input

**Technology:** JFET-input dual, an improved NJM082 (TL082-class) with attention to noise and distortion. NJM2082DD is a noise-screened grade.

## Why enthusiasts rate it

The C-Area wiki page (NJM2082D) finds it heavier and more composed than the TL072CP, with better low- and high-frequency extension. A zigsow review ('072改' / 'improved 072') describes the NJM2082DD as slightly warm like the NJM072 but more neutral, and well suited to classical and clean-tone music. The dad8893 blog includes it in a JFET op-amp listening comparison (TL072 / NJM072 / NJM2082 / OPA2134 / MUSES8920). Kyohritsu (eleshop) sells a noise-screened 'ノイズ選定品' DD grade.
