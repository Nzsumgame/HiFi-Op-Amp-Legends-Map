# AD844 (Analog Devices current-feedback op-amp, used as open-loop DAC I/V)

**Tier** B: widely praised · **Category** High-speed / video crossovers

*Its low-impedance (~50 ohm) current-feedback input and exposed TZ node let DAC DIYers run it as an open-loop I/V stage. Some diyAudio posters rate it above OPA627 I/V.*

**Technology:** Single-channel monolithic current-feedback op amp (current-conveyor topology with an accessible transimpedance/TZ node), fabricated on ADI's junction-isolated complementary bipolar (CB) process. Attribution of the design to Barrie Gilbert is unconfirmed.

## Why enthusiasts rate it

DAC DIY builders praise it as an I/V converter. The DAC's output current goes into the low-impedance inverting input, and the voltage is taken from the TZ node, usually with no global feedback, into a separate buffer. Posts in the long diyAudio thread 'Using the AD844 as an I/V' (more than 120 pages) call it the 'best opamp based I/V so far by a long way' and say it beat the OPA627. They also describe paralleling 2 or 3 AD844s per channel with an OPA627 buffer. These are forum opinions, not measurements.

**Typical uses:** Open-loop current-to-voltage (I/V) conversion for current-output audio DACs, with the TZ node followed by a buffer (an OPA627 in the diyAudio posts), 2-3 paralleled AD844s per channel for a lower-impedance I/V input (diyAudio), High-speed video and pulse amplification (vendor-intended use), Current-conveyor (CCII+) building block

**Caveats:**

- Current-feedback part: the feedback resistor sets the bandwidth, and a capacitor placed directly in the feedback path invites oscillation
- In open-loop TZ use, gain, linearity and output offset depend on the TZ resistor and are not corrected by feedback, so a DC offset needs handling
- 6.5 mA quiescent current per part is significant when several are paralleled
- The only surface-mount package is the 16-lead SOIC_W (JRZ-16); there is no 8-lead SOIC for drop-in swaps
- Performance claims come from subjective forum listening

### Revision chain status

Analog Devices AD844 (sole source; no second source found). Known chain, oldest to newest: the original edition is c. 1989 (only the (c)1989 copyright start dates it; no copy found). Rev. A is missing. Rev. B is missing. Rev. C has no date; it is the old format, 12 pages, held by farnell.com/datasheets/13931.pdf and alldatasheet 48466. Rev. D is missing. Rev. E has no date; it is the old format with a 'REV. E' footer. It is newly confirmed in the already-listed farnell.com/datasheets/77786.pdf, which was previously marked 'possibly F or G'. Rev. F is missing: its date is unknown and it was probably the first new-format 'Data Sheet' edition. Rev. G is dated 2017 by its (c)1989-2017 copyright line. It is held by analog.com/media/.../ad844.pdf, the legacy analog.com/static/imported-files/data_sheets/ad844.pdf (titled 'AD844 (Rev. G)'), radiolocman di=351709 and, per a search summary, the Digi-Key HTML datasheet. The octopart 9797614 copy is titled '... Data Sheet', so it is new format (F or G), but its revision is not shown. Copies with an unknown revision were newly found at alldatasheet 48469 (AD844AN), datasheet4u id=1088520, futurlec, scribd 373710257 and allaboutcircuits. Still missing: the original edition, Revs. A, B, D and F, all revision dates before 2017, and the Rev. F to G change list. Two leads for the missing revisions: seed the two legacy analog.com/static/imported-files paths into the Wayback Machine for older snapshots (likely E/F), and check 1990s ADI Linear Products / Amplifier Reference Manual databooks for Rev. A/B. One unverified item: a search summary mentioned 'revision A adding device classes Q and V, revision B..., revision D adding device type 02'. That wording matches a DLA SMD (5962-series, for AD844S), not the ADI datasheet, so it was not recorded as ADI revisions.

## Counterfeits

No AD844-specific counterfeit reports were found in this pass. Remarked op amps sold on eBay and AliExpress are widely documented (Hackaday, Super-Freq), and diyAudio I/V builds depend on genuine AD844 behaviour. Buy from authorized distributors. Be cautious with loose 'AD844AN/JN' DIPs offered as new stock, because genuine current production is the AD844ANZ.
